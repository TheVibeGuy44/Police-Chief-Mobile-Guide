## Contributor of the week

The block on the home banner reads `contributor.json`:

```json
{"name": "[TX1]PlayerName", "img": "img/contributor.jpg"}
```

Put the player's profile picture in `img/` (a square image works best) and set `name` and `img`. Leave both empty to hide the block. The site picks up the change within about ten minutes.
